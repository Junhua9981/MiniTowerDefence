# 極簡塔防・日夜潮汐 — 流派版

## 啟動

- **Windows**：雙擊 `start.bat`。它會用 Node.js（沒有的話改用 Python）在背景開一個本地伺服器，並在瀏覽器打開 http://localhost:8080/ 。關掉最小化的「MiniTowerDefence server」視窗就會停止。
- **手動**：在這個資料夾執行 `node serve.mjs`（或 `py serve.py`），再打開 http://localhost:8080/ 。
- 不能直接雙擊 `index.html`：ES modules 必須透過 http 載入。
- 需要支援 WebGL2 的瀏覽器（Chrome / Edge / Firefox），並開啟硬體加速。

網址參數：

| 參數 | 作用 |
|---|---|
| `?bench=12000` | 壓力測試：自動鋪防線，讓同屏敵人維持在 12,000 隻，每秒在 console 印出 FPS／模擬耗時／渲染耗時 |
| `&bullets=15000` | 壓力測試時額外讓子彈數維持在 15,000 |
| `&particles=20000` | 壓力測試時讓粒子數維持在 20,000 |
| `?seed=123` | 固定地圖種子 |
| `?degrade=off` | 關閉自動降級（量測或截圖用） |

## 玩法

一般模式 10 天（兩幕），撐到第 11 天黎明即勝利；核心被摧毀即失敗。每天：黎明（安全、增益 +30%、殘影復活、暗晶淨化、選卡）→ 白晝 → 黃昏（紅色箭頭預警主攻方向、公布詞綴）→ 夜晚（大潮）。第 5、10 夜各有一隻首領；最後一夜時間軸隱藏、不能暫停。

- **核心**：開局選一種，就是流派起點。曙光（平衡）、烈日（攻擊）、新月（控制）、潮汐（經濟），各有特色與代價；後三種靠解鎖取得。
- **黎明卡片**：第 2 天起每個黎明 3 選 1，這一局永久生效。卡片分烈光、月影、潮汐、中立四派，同派越多越容易抽到；持有特定兩張會出現進化卡；打倒首領後的黎明可選傳說卡。整個白天都能選，黃昏還沒選就自動拿第一張。可花 15 晶重抽一次。
- **星級與昇華**：攻擊塔靠擊殺升星，牆、礦、冰晶、增幅每撐過一夜升一星，每星 +8%。紫色 5 星的塔可花 300 晶昇華成傳說型態（同種限 1 座）。
- **光爆**：黃昏或夜晚按 `Q`，消耗核心目前 20% 血量，效果依核心而定。每夜一次。
- **暗晶**：夜裡擊殺會在地上留下紫色暗晶，黎明光波掃過時變成晶。
- **首領**：夜之主、深潮、噬光者（第 5 夜三選一），蝕、群母（第 10 夜二選一）。首領出現前一個黎明會預告弱點，當天的卡裡有一張「對策卡」。首領沒倒時黑夜最多延長 60 秒，但其他敵人會被第一道晨光驅散，只剩首領。打倒首領的下一個黎明可以選傳說卡。
- **夜晚詞綴**：一般模式第 7–9 夜、無限模式第 11 夜起，黃昏公布今晚的詞綴（疾行、厚甲、再生、抗寒……）。

**長期發展**

- **光域與燈塔**：只有被照亮的土地能建造。開局照亮核心周圍約 16 格；**燈塔**（`0`）蓋在亮區邊緣能再照亮 9 格，點亮的土地永久屬於你。
- **遺跡**：8 座散落在黑暗中，照亮就領獎勵：晶、金、晶核，或多選一張卡。
- **研究**（`G`）：花晶解鎖。分工程、武器、光三條，各 4 層：地刺、強化牆、維修站、自動工坊／遠視、雷擊塔、共振、速射／燈塔強化、礦業效率、雙槽、白金。白金讓核心與所有建築升到第五階。
- **新建築**（研究解鎖）：**地刺**（`J`，鋪在地上不擋路）、**維修站**（`K`）、**雷擊塔**（`L`，閃電連鎖）。
- **晶核**：首領必掉 3 顆、菁英偶爾掉、遺跡也有。紫色以上的攻擊塔可以鑲 1 顆（研究「雙槽」後 2 顆）：鋒銳、迅捷、遠視、穿甲、霜擊、連鎖、暴擊。三顆同種同稀有度可以合成高一級。
- **會進化的敵人**：第 6 夜起飛群（無視牆壁）、第 7 夜醫者（替周圍回血）、第 8 夜盾衛（周圍敵人受到的直接傷害減半）；無限模式第 11 夜隱影（塔只能在 3.5 格內鎖定）、第 13 夜掘地者（從地下穿過建築直攻核心）。
- **經濟規則**：金礦超過 12 座後效率遞減（研究「礦業效率」可減緩），金礦不吃星級；同類建築每多一座貴 2%（牆不受影響）；卡片可以一直重抽，每次價格加倍。

- **資源**：金（建造、升級）與晶（升到綠色以上、升級核心）。晶來自核心、晶礦（只能蓋在晶脈上）和菁英敵人。
- **階級**：白 → 綠 → 藍 → 紫，每階主要數值 ×1.6。建築不能高於核心的階級；核心升級就是科技進度（藍：夜間脈衝攻擊；紫：脈衝強化、黎明增益延長）。
- **紫色分支**：藍升紫時二選一，改變玩法（例如箭塔的連弩／狙擊、砲塔的集束／重砲）。
- **藍圖**：錢不夠時照樣放，錢夠時依放置順序自動建造。
- **殘影**：被拆的建築留下虛線殘影，下一個黎明被光波掃到時免費復活。

## 操作

**電腦**

| 操作 | 方法 |
|---|---|
| 選擇建築 | `1`–`9` 或點建造列 |
| 放置 | 左鍵；錢不夠會放成藍圖，錢夠時依序自動建造 |
| 畫一整排 | 拖曳＝沿著滑鼠畫線（可轉彎），**往回拖可縮短**；`Ctrl`+拖曳＝矩形，`F` 切換外框／實心 |
| 取消這一筆 | 拖曳中按右鍵或 `Esc`。放開滑鼠才會真的花錢，游標旁會顯示這一筆要蓋幾座、花多少、幾個藍圖 |
| 放完保持建造模式 | 按住 `Shift`（牆預設就會保持） |
| 選取 | 點一下；空地拖曳＝框選多座；雙擊＝選畫面內同類；`Ctrl`+點＝加入／移出多選 |
| 升級 | `U`（升級選取的全部；沒選取時升級游標下的建築）；`Shift`+`U` 升級全部同類 |
| 紫色分支 | `Z`（A）／`C`（B），多選時一起套用 |
| 光爆 | `Q`（黃昏或夜晚，每夜一次） |
| 研究與晶核 | `G` 開關面板；鑲嵌晶核：點紫色以上的攻擊塔，在選取面板裡按「鑲嵌晶核」 |
| 燈塔／研究建築 | `0` 燈塔；`J` 地刺、`K` 維修站、`L` 雷擊塔（研究後才出現） |
| 選卡 | 點上方的卡片；「收起」可以先關掉，整個白天都能選 |
| 賣出／目標策略 | `X`／`T`（多選時一起處理） |
| 取消 | 右鍵／`Esc`；右鍵藍圖或殘影可移除 |
| 暫停（仍可建造）／速度 | `空白鍵`／`Tab` |
| 平移／縮放 | `WASD`、方向鍵、中鍵拖曳／滾輪 |
| 音量／靜音 | `V` 循環 高→中→低→靜音；`M` 靜音 |
| 說明／效能／重來 | `H`／`F3`／`R` |

**手機與平板（橫向）**

- 點建造列選建築，手指在地圖上點＝放置、拖曳＝畫線（往回拖可縮短，放上第二根手指取消整筆）；右側按鈕循環切換「畫線 → 外框 → 實心」。
- 沒在建造時：點建築＝選取；單指拖曳＝平移；雙指＝縮放與平移；連點兩下＝選畫面內同類；長按建築＝選同類；長按藍圖或殘影＝移除。
- 右側「框選」打開後，拖曳可框選多座建築，選取面板裡可一起升級或賣出。
- 右側還有開始／暫停、速度、音量、光爆（黃昏與夜晚才出現）、取消。

**手機怎麼開**

- 同一個 Wi-Fi：用 `start.bat` 開伺服器後，伺服器視窗會印出「手機（同一個 Wi-Fi）→ http://192.168.x.x:8080/」，用手機瀏覽器開那個網址。第一次 Windows 可能會問防火牆，要允許「私人網路」。
- 也有一份發布在 claude.ai 的線上版，手機登入 claude.ai 就能開。

## 新手引導

第一次開啟預設打開，規劃畫面可以勾選或取消「新手引導」。參考宮本茂「用關卡安排來教」的做法，分散在前 5 天：

- 建築逐日解鎖：第 1 天只有牆、金礦、箭塔；第 2 天晶礦；第 3 天散射塔、砲塔；第 4 天冰晶塔、稜鏡塔；第 5 天增幅塔。
- 第一夜敵人只有 6 成、第二夜 8 成，讓第一次失誤不致命。
- 提示只在剛好需要的時刻出現一句（第一個黃昏教畫牆、第一次選卡、第一次可以升級核心、第一次出現殘影……），做到就消失，不暫停、不擋操作，也可以按「知道了」關掉。
- 第 6 天黎明自動結束，之後的局預設不再開啟。

## 模式

- **一般模式**：撐到第 6 天黎明。第 5 夜的夜之主在黃昏就從主攻方向出現；牠還沒倒下黑夜就不會結束（最多延長 60 秒）。
- **一般模式**：10 天。勝利後可以按「繼續挑戰無限」把這一局帶進無限模式。
- **無限模式**：沒有終點。第 10 天之後敵人每天變硬，每 5 夜一隻首領（第 15 夜起五隻輪替，再次登場會更強並帶護衛），第 11 夜起每夜 1 個詞綴、第 16 夜起 2 個。死亡時記錄最佳天數。同屏敵人上限 22,000 隻以保持流暢。
- **解鎖進度**（存在瀏覽器）：第一次打倒首領解鎖烈日核心、一般模式勝利解鎖新月核心、無限模式撐到第 15 天解鎖潮汐核心；累積撐過 10、20 夜各加入 4 張新卡；五種首領都打倒過，傳說卡池全開。網址加 `?unlock=all` 可以全部打開試玩。
- 規劃畫面切換模式與核心；也可以用網址 `?mode=endless`。

## 部署到 Cloudflare Pages

整個遊戲是純靜態網站（`index.html` + `src/`），不需要建置工具或後端。`node tools/build-dist.mjs` 會產生乾淨的 `dist/` 資料夾（另附 `_headers`，讓更新後手機不會卡在舊版快取）。

**方法 A：拖曳上傳（不用裝任何東西）**
1. 登入 https://dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets。
2. 專案名稱填 `mini-tower-defence`，把 `mini-tower-defence-site.zip`（或整個 `dist` 資料夾）拖進去 → Deploy。
3. 網址是 `https://mini-tower-defence.pages.dev`（名稱被占用時以 Cloudflare 顯示的為準）。之後更新：同一個專案 → Create deployment → 再拖一次。

**方法 B：一鍵指令（需要 Node.js）**
雙擊 `deploy-cloudflare.bat`。它會重建 `dist/`，再用 Cloudflare 官方的 wrangler 上傳；第一次會開瀏覽器請你登入並建立專案，之後每次更新都只要再雙擊一次。

## 範圍

P1：地圖、核心、流場與拆牆、日夜循環、WebGL2 instancing + SDF、壓力測試。
P2：全部 9 種建築與 6 種敵人（含菁英、夜之主）、四階級與紫色分支、晶與晶礦、藍圖、黎明復活、完整介面與說明浮窗。

P3：
- 夜晚光照：場景先畫進離屏緩衝，再乘上 1/4 解析度的光照貼圖（核心、塔、牆、爆炸、雷射、燃燒帶、菁英與首領各自是光源），光照範圍外變暗。
- Bloom：亮部縮小到 1/4 → 兩次高斯模糊 → 疊回畫面。白天門檻高（只有雷射、爆炸會發光），夜晚門檻降低。
- 自動降級：幀時間連續超過 18 ms 時依序「粒子減半 → 關閉 bloom → 光照貼圖降到 1/8 並關掉敵人光暈」，持續順暢 4 秒後反向開回。
- 音效（Web Audio 程式合成）：箭、散射、砲擊、雷射掃頻、死亡點擊聲、爆炸、建造、升級琶音、晶的叮聲、冰凍、核心脈衝、核心警示音、黃昏低頻嗡鳴、夜晚鐘響、黎明上行和弦、首領出現與脈衝、失敗下行音。同類音效同時最多 6 個，並依當幀事件數自動降低音量；經過壓縮器避免爆音。`M` 靜音（會記住）。
- 勝利演出：第 6 天黎明的光波更強，全畫面慢動作 0.5 秒，建築被光波掃到時依序亮起，掃完才出現結算。
- 「快被突破」提示：最近被打、血量低於一半的建築會有紅色脈動光暈，白天夜晚都看得到。

流派版：一般模式 10 天、5 種首領與預告、核心種類、黎明卡片（24 張＋3 進化＋5 傳說）、星級與昇華、光爆、暗晶、夜晚詞綴、解鎖進度、分散在前 5 天的新手引導。架構與取捨見「流派與成長系統架構」文件。

與需求書不同的數值：

- 一般模式改為 10 天：敵人血量每天 ×1.45、拆建築傷害每天 ×1.25（10 天的總成長由自動測試玩家調整），夜晚數量從 800 到 21,000。
- 首領血量隨天數 ×(天數/5)^1.3，再次登場 ×1.5。
- 再生牆每秒回 2%（原本設計 4% 時牆幾乎打不穿）。
- 砲塔爆炸傷害從中心 100% 衰減到邊緣 40%。

## 結構

```
src/sim/   純邏輯模擬（不碰 DOM / WebGL，可在 Node 執行）
  defs.js    所有數值與 BAL 平衡參數、核心種類、首領、詞綴
  cards.js   黎明卡片、進化卡、傳說卡與卡池解鎖
  （研究、晶核、新敵人、光域都在 defs.js 定義，world.js 實作）
  map.js     地圖生成
  flow.js    流場（Dial 演算法）
  world.js   世界：SoA 陣列、出怪、移動、互斥、索敵、子彈、光環、日夜、階級、藍圖、殘影
src/render/  WebGL2 渲染（gl.js）、場景組裝（scene.js）、特效（fx.js）
src/ui/      DOM 介面（ui.js）、新手引導（guide.js）
src/main.js  主迴圈（60 Hz 固定步長 + 插值）、輸入、鏡頭、自動降級
tools/       Node 量測與測試
```

## 量測工具

```
node tools/bench.mjs 12000 900          # 模擬耗時：敵人數、量測步數
node tools/bench.mjs 12000 900 15000    # 再加 15,000 發子彈
node tools/autoplay.mjs 5               # 自動玩家：完整／精簡／不防守 × 5 個種子
node tools/autoplay.mjs 3 noupgrade     # 只蓋白色建築、完全不升級
node tools/autoplay.mjs 2 full normal 1,2,3   # 指定核心種類（0 曙光 1 烈日 2 新月 3 潮汐）
node tools/diag.mjs 20268941 10         # 印出某個種子第 N 夜的首領與核心狀態
node --expose-gc tools/edge.mjs         # 邊界情況與記憶體
```
